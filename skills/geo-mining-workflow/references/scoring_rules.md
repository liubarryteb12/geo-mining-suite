# GEO-Score-100 数据集质量与适配度打分体系规范

## 1. 维度与权重定义

| 维度编号 | 维度名称 | 权重 | 判定细则 |
| :--- | :--- | :---: | :--- |
| **Dim 1** | **样本规模 (Sample Size)** | **25分** | $\ge 60$ 例得 25分；$30 \sim 59$ 例得 22分；$15 \sim 29$ 例得 18分；$8 \sim 14$ 例得 10分；$< 8$ 例得 0 分并触发一票否决。 |
| **Dim 2** | **原始数据质量 (Raw Data)** | **30分** | 包含原始芯片 RAW.tar (CEL/IDAT)、RNA-seq 原始 Counts 矩阵、单细胞 10x 三件套/h5 得 30 分；包含 FPKM/TPM 归一化后矩阵得 20 分；仅包含 Series Matrix 矩阵得 15 分；缺失补充文件得 0 分并触发一票否决。 |
| **Dim 3** | **临床表型丰度 (Phenotype Richness)** | **20分** | 基底对照/疾病二分类得 8 分；含年龄/性别/BMI 等人口学信息加 5 分；含分期/纤维化/生化指标加 5 分；明确组织穿刺/活检标本加 2 分（最高 20 分）。 |
| **Dim 4** | **测序平台成熟度 (Platform Maturity)** | **15分** | 主流高引用平台（GPL570, GPL11532, GPL24676, GPL30172 等）得 15 分；标准 GPL 平台得 10 分；冷门或非标平台得 5 分。 |
| **Dim 5** | **文献与设计严谨度 (Credibility)** | **10分** | 包含已发表 PubMed ID 得 8 分；包含清晰 Overall Design 描述加 2 分。 |

## 2. 硬性一票否决规则（Hard Veto）

* 若样本数 $< 8$，或补充原始文件项得分为 0，数据集质量总分强制封顶为 **45 分**（直接判定为 C 级淘汰）。
* 严禁将 C 级淘汰数据集作为训练集或主验证集。
