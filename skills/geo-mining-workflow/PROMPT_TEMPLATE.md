### 二、 核心数据集真实性与原始文件证实卡（逐个证实 Top 2~3）
对评分排名前列的优质数据集，逐一输出证实卡片，每项必须基于 NCBI 真实抓取数据：
- **GSE 编号与官方链接**：[GSE...](官方链接)（评级：X 级，GEO-Score-100 综合得分：X分）
- **官方文献证实**：PubMed ID 与论文标题（如有发表附 PubMed 直达链接，未发表注明）
- **实验平台与组织来源**：GPL 编号、平台仪器名称及真实取样组织
- **真实分组与样本量核验**：
  - 官方 Overall Design 实验设计摘要：...

- **原始数据与补充文件证实（核心关键）**：
  - NCBI Supplementary file 栏目下抓取到的真实文件名清单（如 `GSEXXXXX_RAW.tar` 或 `...raw_counts.txt.gz`）
