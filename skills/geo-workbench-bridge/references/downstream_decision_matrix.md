# 下游决策与湿实验反哺指引

本文档给出从高维生信结果走向实验设计的通用决策逻辑，可用于空间转录组、单细胞与 Bulk 联合分析。示例中的基因与组织均为占位符。

## 一、课题边界判定

启动前必须明确文章篇数与实验进度：

| 课题模式 | 判断依据 | 处理方式 |
| :--- | :--- | :--- |
| 单篇多模态 | 多个表型服务于同一核心机制 | 一个项目，L1 到 L2 到 L3 渐进推进 |
| 多篇独立 | 各篇有独立的核心问题与验证路径 | 每篇独立建项，不混在同一份需求单 |

混合建项会导致样本、对照组与结论互相污染，后续无法拆分，属于必须避免的错误。

## 二、靶点状态

### 1. 已锚定靶点

适用于基因已经进入细胞转染或动物干预阶段的情况。

- `biologicalPriors.targetKoGene` 填该基因。
- 保留 `spatial_knockout` 与 `dr_post_analysis`，空间线为 17 步。
- 原位虚拟敲除的预测结果与离体敲低实验互相印证。

### 2. 无偏探索

适用于只有候选基因列表、尚未决定主攻方向的情况。

- 候选基因全部写入 `focusGenes`。
- `targetKoGene` 留空，`isExploratory: true`。
- 空间线自动降为 15 步，不含敲除。
- 用共定位系数、区域富集倍数、细胞类型特异性三项指标排序，再决定实验对象。

## 三、结果到实验的决策表

| 观察到的现象 | 可能的机制解释 | 建议的实验设计 |
| :--- | :--- | :--- |
| 靶基因在特定区域边界呈梯度表达 | 局部应激或代偿反应 | 组织切片免疫荧光验证空间梯度；按时间点取样检测蛋白丰度变化 |
| 反卷积显示靶基因富集于某一类免疫细胞 | 该细胞亚群主导炎症或清除功能 | 切片双染标记物与靶蛋白；选用对应细胞系做刺激或敲低实验；检测吞噬或分泌表型 |
| 靶基因高表达于实质细胞 | 代谢或结构功能改变 | 原代细胞与邻近细胞共培养；检测屏障、分泌或存活指标 |
| 靶基因富集于内皮细胞并伴随屏障相关基因下降 | 血管通透性改变 | 内皮细胞模型测跨膜电阻与通透性；动物水平做血管渗漏实验 |
| 靶基因与氧化磷酸化评分强相关 | 线粒体呼吸链活性改变 | Seahorse 检测耗氧率与 ATP 产出；JC-1 检测膜电位 |
| 配体受体分析提示某条通讯轴增强 | 细胞间信号驱动表型 | 共培养加中和抗体或受体阻断；检测下游通路磷酸化水平 |

原则：每条实验建议都必须能追溯到一条具体的分析结果，不写没有数据支撑的泛泛建议。

## 四、HTML 全景报告交付标准

报告用于和合作者对齐方案，建议满足：

- 单文件，自包含 CSS 与流程图脚本，离线可打开。
- 首屏给出三条分析线的递进关系与数据依赖。
- 每个数据集展示样本量、平台、原始数据等级与总分。
- 明确标注靶点状态与虚拟敲除策略。
- 附实验决策矩阵，注明每条建议对应的分析证据。
- 不使用外部 CDN，不嵌入任何本地绝对路径。

## 五、常见错误

- 把多篇独立论文塞进一个项目，导致样本分组与对照组冲突。
- 有虚拟敲除步骤但不填 `targetKoGene`，导入即报错。
- 只有 `modIds` 没有 `pipelineDag`，界面复选框全空。
- 参考文献缺 `path` 或 `size`，前端列表被过滤为空。
- 样本编号不是 GSM 开头，或分组总数与 `dataSource.sampleCount` 不一致。
